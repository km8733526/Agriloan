# 🌾 AgriLoan Credit Scorer — Backend API

> **Production-grade Flask REST API that turns a farmer's loan application into an ML-powered credit decision in under a second.**

Built with XGBoost, SQLite, and real soil/weather enrichment — designed to pair with the [AgriLoan frontend](../frontend).

---

## ✨ What Makes This Interesting

Most credit scorers are black boxes. This one shows its work:

- 📍 **GPS → soil data** — latitude/longitude resolves to soil type, pH, nitrogen, phosphorus, and potassium levels
- 🌧️ **GPS → climate data** — same coordinates pull annual rainfall, drought risk, and monsoon reliability scores
- 🤖 **10-feature XGBoost pipeline** — `StandardScaler` + `XGBClassifier`, trained on 8,000 synthetic agricultural loan records (~81.6% accuracy, ~0.90 AUC)
- 📊 **Trust Score 0–100** — derived from repayment probability, mapped to Approved / Review / Rejected with loan terms and EMI baked in

## ⚡ Quick Start

### One-command setup (recommended)

```bash
chmod +x setup.sh && ./setup.sh
```

This script: creates a virtualenv → installs dependencies → trains the model → initialises the DB → runs smoke tests → starts the server.

### Manual setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the ML model
python train_model.py
# → Accuracy: ~81.56% | ROC-AUC: ~0.90
# → Saved to model/credit_model.pkl

# 3. Start the server
python app.py                                          # development
gunicorn -w 4 -b 0.0.0.0:5000 "app:create_app()"     # production
```

## 🔌 API Reference

### `POST /evaluate`
Submit a loan application and receive a full credit evaluation.

**Request:**
```json
{
  "fullName": "Rajesh Kumar Singh",
  "aadhaar": "1234-5678-9012",
  "phone": "9876543210",
  "district": "nashik",
  "village": "Yeola",
  "surveyNumber": "123/45/A",
  "landSize": 8,
  "irrigation": "drip",
  "ownership": "owner",
  "primaryCrop": "cotton",
  "cropDiversity": 3,
  "yield1": 30, "yield2": 35, "yield3": 38,
  "latitude": 19.99, "longitude": 73.78
}
```

**Response `201`:**
```json
{
  "trust_score": 82,
  "risk_level": "Low",
  "status": "Approved",
  "repayment_probability": 0.8234,
  "loan_terms": {
    "max_loan_amount_inr": 500000,
    "interest_rate_pct": 7.5,
    "tenure_years": 5
  },
  "emi_monthly": 10012.45
}
```

**Risk tiers:**

| Trust Score | Risk | Decision |
|---|---|---|
| 80 – 100 | 🟢 Low | Approved — ₹5,00,000 @ 7.5% / 5 yr |
| 60 – 79 | 🟡 Medium | Review — ₹2,50,000 @ 9.5% / 3 yr |
| 0 – 59 | 🔴 High | Rejected |

## 🧠 ML Model Details

**Algorithm:** XGBoost (falls back to sklearn `GradientBoostingClassifier` if not installed)  
**Pipeline:** `StandardScaler` → `XGBClassifier`  
**Training data:** 8,000 synthetic samples with realistic agricultural feature distributions  
**Evaluation:** ~81.6% accuracy, ~0.90 ROC-AUC, 5-fold CV

**Feature vector (10 features, order matters):**

| # | Feature | Source |
|---|---|---|
| 0 | `land_size` | Form input (acres) |
| 1 | `crop_diversity` | Form input |
| 2 | `average_yield` | 3-year average from form |
| 3 | `soil_ph` | Soil service (GPS) |
| 4 | `rainfall` | Weather service (GPS, mm/yr) |
| 5 | `irrigation_score` | Encoded: drip=4, canal=3, borewell=2, rain-fed=1 |
| 6 | `ownership_score` | Encoded: owner=3, lease=2, tenant=1 |
| 7 | `drought_risk_score` | Weather service: low=1, medium=2, high=3 |
| 8 | `nitrogen_score` | Soil service: low=1, medium=2, high=3 |
| 9 | `yield_trend` | Linear slope of 3-year yield series |

## 🗃️ Database Schema (SQLite)

Three tables, all with foreign-key enforcement and WAL journal mode:

**`farmers`** — personal details (name, Aadhaar, phone, district, village)  
**`land_details`** — survey number, size, irrigation type, coordinates  
**`loan_applications`** — ML outputs + crop data (trust score, risk, status, soil/weather snapshots)

Indexes on `status`, `created_at`, `farmer_id`, and `trust_score` keep dashboard queries fast.

## 🌐 Frontend Integration

In your frontend `js/app.js`, swap the localStorage prediction block for a real API call:

```javascript
fetch('https://your-backend.com/evaluate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(formData)
})
.then(res => res.json())
.then(data => {
  localStorage.setItem('evaluationResult', JSON.stringify(data));
  window.location.href = 'result.html';
});
```

CORS is pre-configured for `https://km8733526.github.io`. Update the origin list in `app.py` → `create_app()` for your own domain.
